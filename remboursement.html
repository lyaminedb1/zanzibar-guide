Politique de remboursement

Dernière mise à jour : [DATE]

Avant le téléchargement

Si vous n'avez pas encore téléchargé le guide, vous pouvez demander un remboursement complet dans les 14 jours suivant votre achat, sans avoir à vous justifier.

Après le téléchargement

Le guide est un contenu numérique livré immédiatement. Une fois le fichier téléchargé, il ne peut plus être « rendu ». Nous ne remboursons donc pas un guide déjà téléchargé, sauf dans les cas ci-dessous.

Les cas où nous remboursons toujours

  • Le fichier est endommagé ou ne s'ouvre pas, et nous ne parvenons pas à vous envoyer une version qui fonctionne.
  • Vous avez été débité deux fois pour le même achat.
  • Le contenu reçu ne correspond pas à ce qui est décrit sur la page de vente.
